# Project Profile

## Summary
- Type: presentation-style static web artifact
- Stack: single-page HTML with local assets and images
- Primary artifacts: `index.html`, image assets, presentation visuals

## Default Squad
- Primary: `Visual Storyteller`
- Supporting: `UI Designer`, `Frontend Developer`, `Reality Checker`

## Routing Cues
- If user asks for layout, visual hierarchy, slide-like storytelling, or branding tweaks:
- Switch to: `Visual Storyteller` + `UI Designer`
- If user asks for implementation changes in markup, styling, or interactions:
- Switch to: `Frontend Developer`
- If user asks for verification, responsiveness, or readiness checks:
- Switch to: `Reality Checker`

## Current Goals
- Maintain a presentation-like web deliverable with strong visual communication
- Keep edits practical inside a single-page static artifact unless the repo evolves

## Constraints
- Prefer minimal structure changes unless a redesign is clearly requested
- Preserve compatibility with local static asset workflow

## Working Style
- Prefer small, verifiable changes before expanding scope

## Handoff Triggers
- Switch to `Frontend Developer` when storytelling work becomes implementation work
- Switch to `Reality Checker` when implementation work becomes release validation

## Escalation Policy
- Switch to high-agency mode after 2 repeated failures on the same path
- Require verifiable evidence before claiming completion
