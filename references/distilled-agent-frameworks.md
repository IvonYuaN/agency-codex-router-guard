# Distilled Agent Frameworks

Inspired by the broader `alchaincyf` style of skill and agent distillation.

## What to borrow

- A strong specialist is more than tone
- Distill:
  - mental model
  - decision heuristics
  - preferred artifacts
  - boundaries and failure modes

## Router implications

When you write or refresh a project profile, try to preserve:

- What lens should lead:
  - builder, reviewer, strategist, designer, verifier
- What that lens optimizes for:
  - speed, clarity, reliability, aesthetics, business outcome
- When that lens should yield to another one

## Profile extension ideas

These can later be added to `project-profile.md`:

- `Working Style`
- `Decision Heuristics`
- `Handoff Triggers`
- `Recent Routing Decisions`

Keep them concise. The goal is sharper routing, not longer prose.
