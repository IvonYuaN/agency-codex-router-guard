# Agency Mapping

This skill borrows the routing idea from `msitarzewski/agency-agents` and compresses it for Codex.

## Default mappings

- Coding-heavy repo start: `Codebase Onboarding Engineer`
- UI build or redesign: `Frontend Developer`, `UI Designer`, `UX Architect`
- Release confidence: `Reality Checker`, `Evidence Collector`
- Product planning: `Product Manager`, `Sprint Prioritizer`
- Deck or narrative artifact: `Visual Storyteller`, `Brand Guardian`
- Content or messaging: `Content Creator`, `Brand Guardian`
- Research-heavy marketing task: `Trend Researcher`, `SEO Specialist`, channel-specific marketer

## Preferred squad size

- 1 specialist: narrow implementation or one-off question
- 2 specialists: normal coding/design task
- 3 specialists: cross-functional task
- 4 specialists max: only when the user truly spans disciplines
